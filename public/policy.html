name_exact0.999 similarity ratio (0 to 1)At or above this two names are treated as the same after normalisation, so an identifier-grade match is exact, not fuzzy.procurementNothing practical changes; it already means "identical after normalisation".Near-identical names would count as exact and skip the reviewer, weakening name assurance.
name_similar0.85 similarity ratio (0 to 1)Between this and name_exact a name difference is a slight variant (WARN for a reviewer), never a rejection; below it the names are materially different (FAIL).procurementMore small spelling variants fall to FAIL, so more vendors are held as a name mismatch (more friction).More genuinely different names pass as "similar", so weaker name checking and higher unsafe risk.
ocr_min_doc_conf0.6 mean OCR word confidence (0 to 1)Below this the whole photo or scan is treated as unreadable and held for a reviewer rather than guessed at.complianceMore photos are called unreadable, so more vendors are asked for a sharper image (more friction).Poorer images are accepted, raising the chance of a misread value being trusted.

ocr_dpi300 dots per inchRender resolution for image-only PDF pages before OCR; 300 dpi is the usual floor for reliable text.complianceSharper rendering and slightly better OCR, at more time and memory per page.Faster OCR but more misreads on small print.
