# Kyvo live demo

Vendor onboarding verification for the Zamp PS-2 case study. Deterministic Python rules decide APPROVED, PENDING or REJECTED; no LLM and no API key.

- Source: https://github.com/Ashrith-work/kyvo
- Website: https://ashrith-work.github.io/kyvo/

Try it: open **New Submission** and run a bundled sample scenario.

This is a shared demo. Every visitor sees the same SQLite database, and it resets whenever the Space restarts. All data is fictional.
